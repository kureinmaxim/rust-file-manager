# Мини-приложение для врача

Рабочее пространство реализовано вместе с TelegramOnly: «Помощь врача» отделена
от «Остальных файлов», документы собраны по обращениям. Подробная инструкция
и контракт находятся в TelegramOnly: `docs/files/DOCTOR_WORKSPACE.md`.

Обновите оба приложения. Новых настроек и ключей не нужно: используется текущий
внутренний API. Бот должен быть запущен с обновлённой версией; администратор
явно включает фичу конкретному врачу. Доступ к медицинским данным проверяет
бот; файловый менеджер проверяет Telegram-сеанс и права на выбираемый файл.

Новые публичные маршруты `/api/v1/doctor/jobs` и `/api/v1/doctor/jobs/<id>`
находятся под прежней проверкой Bearer. Новые внутренние маршруты
`/internal/v1/doctor/jobs` и `/internal/v1/doctor/jobs/<id>/done` находятся под
прежней проверкой служебного токена. Содержимое не пишется на диск FM;
результаты и исходные документы очереди удаляются из памяти по TTL.

На iPhone источник «С iPhone / iCloud Drive» открывает системный выбор DOCX;
каталог iCloud выбирается пользователем в «Файлах». Для сохранения результата
есть скачивание и «В чат». Существующая загрузка обычных файлов и с ПК сохранена.

## Проверки

`cargo test --workspace --locked`,
`cargo check --workspace --locked`,
`cargo clippy --workspace --all-targets --locked -- -D warnings`.

Дополнительно: `node deploy/tests/doctor-api.test.mjs` проверяет повтор POST с
тем же request_id при потере ответа и отсутствие повторной генерации при poll.

Для локальной проверки браузером есть тестовый HTTP-сервер на случайном порту
localhost (только cfg(test), синтетические аккаунты и тестовая подпись):

```sh
DOCTOR_UI_RUNTIME=/tmp/doctor-test-runtime.json cargo test doctor_tests::browser_harness -- --ignored --nocapture
```

Путь runtime должен быть новым. Файл содержит только синтетический initData,
порт и временную папку загрузок. Продакшн-проверка подписи Telegram не меняется.
Для полного сценария запустите `doctor_jobs_loop` TelegramOnly с временным
хранилищем, тестовым пользователем 101 с включённой фичей и подставленным ответом
ИИ. Реальные настройки, документы и ключи для такой проверки не используются.
